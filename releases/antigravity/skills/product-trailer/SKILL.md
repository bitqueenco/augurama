# Product trailer

Start with the direct-video workflow in this plugin. The product itself, its current working behavior, brand identity, and the user's approved communication goal are the source of truth.

Inspect the relevant README, AGENTS.md hierarchy, current branch and working product only when access and scope are authorized. Prefer actual screenshots or a recording of the current product to invented UI. Propose a short shot sequence that distinguishes actual product capture from generated cinematic material. Never claim an unimplemented feature works, invent business results, or imply a generated UI is a screen recording.

Keep a local reference selection list with purpose and provenance. Select only final brand assets and approved captures; exclude source archives, personal records, credentials and unrelated work. The remote video service does not need the repository. For local-only media, use the secure desk's upload picker unless the host has an actual transferable file attachment. Do not upload to a public image host as a workaround.

Use the `product` recipe through the live prepare schema. Preserve exact logos, legible UI and copy where possible, but warn that generative reconstruction may distort exact text. Keep critical typography and product evidence in captured/edited footage rather than promising an image model can reproduce it perfectly. The current service generates clips; it is not a lossless NLE or an app-store publishing service.

Show the complete contract and hold for the person to approve. Review the resulting clip against the claims, source captures, brand, timing, audio and safe areas. A repair requires a new contract and approval; never silently regenerate.
